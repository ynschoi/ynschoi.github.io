# 픽셀 영양제 선반 — 영양제 부자 탈출

## 만든 이유
남들이 좋다는 영양제를 몸이 찌뿌둥하거나 잠이 안 올 때마다 하나씩 사 모으다 보니, 영양제 통만 한가득이 됐다.
너무 많이 먹으면 안 될 것 같아서 이러지도 저러지도 못하고, 다시 먹으려니 왜 샀는지도 기억이 안 났다.

**목표:** 영양제 부자에서 탈출하기. 남들이 좋다고 하는 것을 근거로 확인하기.

## 하는 일
1. **겹침·상한 확인:** 같은 성분을 모든 제품에 걸쳐 원소 무게로 합산하고 상한과 비교한다. 같은 목적의 제품이 여러 개면 알려 준다.
2. **근거 표시:** 모든 판단에 근거 등급(A 라벨, B 공공기관, C 논문, D 근거 약함)과 출처 링크를 붙인다.
3. **왜 샀는지 기록:** 통마다 산 이유를 적어 둔다.
4. **정리:** 통마다 "계속 / 필요할 때만 / 쉬기"를 고른다. 결정은 사용자가 하고, 앱은 근거만 보여준다. 쉬는 통은 계산에서 뺀다.
5. **복용 체크와 잔량:** 오늘 먹을 것을 체크하면 남은 개수가 줄고, "○일 남음"이 표시된다.

## 원칙
- 데이터는 기기 브라우저(localStorage)에만 저장한다. 서버로 보내지 않는다.
- 정보 제공만 하고 진단·추천은 하지 않는다. 문구는 "라벨 기준 / 상한 대비 % / 출처" 형식으로 쓴다.
- 제휴 링크는 `AFFILIATE_ENABLED=false`로 꺼 둔다. 켤 때는 수수료 고지를 함께 넣는다.
- 근거 원본 DB는 `myworkout/supplements/evidence/`에 있다. 앱에는 그 요약본이 들어 있다.

## 파일
- `index.html`: 앱 전체 (HTML, CSS, JS가 한 파일)
- `sw.js`, `manifest.webmanifest`, `icon-*.png`: 홈 화면 설치와 오프라인 사용
- `fonts/`: Galmuri11 픽셀 폰트 (SIL OFL 1.1)
